## Scope of Work

Development of the **V League** sports platform—a comprehensive athletics competition, scoring, and ranking system:

1. **Database Architecture & Engine**  
   - 15-table PostgreSQL/Supabase schema (
      - `profiles`, 
      - `competitions`, 
      - `events`, 
      - `competition_events`, 
      - `event_attempts`, 
      - `event_results`, 
      - `registrations`, 
      - `scoring_systems`, 
      - `scoring_rules`, 
      - `scoring_bonus_rules`, 
      - `points_ledger`, 
      - `blogs`, 
      - `contact_messages`
      - +4 `material views`).  
   - Row-Level Security (RLS) policies implemented.  
   - 8 custom database functions/triggers (
     - `award_points`, 
     - `calculate_rankings`, 
     - `calculate_best_performance`, 
     - `recalculate_event`, 
     - `clear_points`, 
     - `refresh_standings`, 
     - `handle_new_user`, 
     - `rls_auto_enable`).

2. **Web Platform**  
   - SvelteKit + Tailwind CSS application featuring authentication, homepage, competitions hub with registration, global ranking board, athlete profiles and point ledgers, blog, and contact sections. Fully optimized and ready to deploy.

3. **Deployment, Configuration & Handover**  
   - Environment setup, secret/credential configuration, complete source code handoff, and dedicated support during launch.
